## Pitwall

A workstation for coding agents. One window, every tool as a tile: run Claude Code, Codex, Gemini CLI or any terminal agent side by side, with a file viewer, code review, web pages and an inbox for agents' questions beside them.

Free and open source (Apache-2.0) · macOS, Linux, Windows (preview)
